DDSファイル読み取り実装手順（MyEngineGameプロジェクト）

========================================
1. 必要なライブラリとヘッダーのインクルード
========================================
- DirectXTexライブラリの準備
- #include <DirectXTex/DirectXTex.h>
- StringUtility（文字列変換用）のインクルード
- SrvManager（シェーダーリソースビュー管理）のインクルード

========================================
2. TextureManagerの初期化
========================================
- DirectXCommonとSrvManagerのポインタを受け取り
- デスクリプタヒープの準備
- 管理用のunordered_map<string, TextureData>を初期化 (textureDatas)
- シングルトンパターンで実装

========================================
3. DDSファイル読み込み処理（LoadTexture関数内）
========================================

3-1. ファイル存在確認
- GetFileAttributesA()でファイルの存在をチェック
- 存在しない場合はデフォルトテクスチャを読み込み
- INVALID_FILE_ATTRIBUTESの場合はfalseを返す

3-2. 拡張子判定とDirectXTex呼び出し
```cpp
if (filePath.ends_with(".dds")) {
    // DDSファイル専用のローダーを使用
    hr = DirectX::LoadFromDDSFile(filePathW.c_str(), DirectX::DDS_FLAGS_NONE, nullptr, image);
} else {
    // 通常ファイル（PNG、JPEG等）用のローダー
    hr = DirectX::LoadFromWICFile(filePathW.c_str(), DirectX::WIC_FLAGS_FORCE_SRGB, nullptr, image);
}
```

3-3. エラーハンドリング
- HRESULTのFAILED()チェック
- 失敗時はstd::runtime_errorをthrow

========================================
4. ミップマップ処理
========================================

4-1. 圧縮フォーマット判定
- DirectX::IsCompressed(image.GetMetadata().format)でDDS圧縮状態をチェック

4-2. ミップマップ生成分岐
- 既に圧縮済み → そのまま使用（mipImages = std::move(image)）
- 非圧縮 → DirectX::GenerateMipMaps()でミップマップ生成
  * TEX_FILTER_SRGBフィルターを使用
  * 生成失敗時はruntime_errorをthrow

========================================
5. D3D12リソース作成
========================================

5-1. テクスチャリソース作成
- dxCommon_->CreateTextureResource(metadata)でGPUリソースを作成
- メタデータから適切なフォーマット、幅、高さ、ミップレベルを設定

5-2. データアップロード
- dxCommon_->UploadTextureData()でCPUからGPUへデータ転送
- dxCommon_->CommandKick()でコマンド実行（重要！テクスチャアップロード後は必須）

========================================
6. SRV（Shader Resource View）作成
========================================

6-1. Cubemap判定ロジック
```cpp
bool isCubemap = textureData.metadata.IsCubemap() || 
                (textureData.metadata.arraySize == 6 && 
                 textureData.metadata.dimension == DirectX::TEX_DIMENSION_TEXTURE2D) ||
                (filePath.ends_with(".dds") && 
                 (filePath.find("cubemap") != std::string::npos || 
                  filePath.find("cube") != std::string::npos ||
                  filePath.find("skybox") != std::string::npos ||
                  filePath.find("airport") != std::string::npos ||
                  filePath.find("rostock") != std::string::npos));
```

6-2. SRVインデックス割り当て
- srvManager_->Allocate()でSRVインデックスを取得
- srvManager_->GetCPUDescriptorHandle()でCPUハンドル取得
- srvManager_->GetGPUDescriptorHandle()でGPUハンドル取得

6-3. SRV作成分岐
- Cubemapの場合：srvManager_->CreateSRVForTextureCube()
  * テクスチャフォーマットとミップレベル数を指定
- 通常テクスチャ：srvManager_->CreateSRVForTexture2D()
  * テクスチャフォーマットとミップレベル数を指定

========================================
7. 管理用データ構造への登録
========================================

7-1. TextureData構造体の設定
- filePath：ファイルパス
- metadata：DirectX::TexMetadata
- resource：Microsoft::WRL::ComPtr<ID3D12Resource>
- srvIndex：uint32_t
- srvHandleCPU：D3D12_CPU_DESCRIPTOR_HANDLE
- srvHandleGPU：D3D12_GPU_DESCRIPTOR_HANDLE

7-2. マップへの登録
- textureDatas[filePath] = textureDataでマップに登録
- 以降はファイルパスをキーとして高速アクセス可能

========================================
8. エラーハンドリング
========================================

8-1. try-catch文での例外処理
- std::exceptionをキャッチ
- エラーメッセージをOutputDebugStringA()で出力

8-2. フォールバック処理
- 失敗時はLoadDefaultTexture()を呼び出し
- 1x1の白テクスチャを動的生成してデフォルトとして使用

========================================
9. 実際の描画での使用（Skybox例）
========================================

9-1. RootSignatureの設定
- D3D12_DESCRIPTOR_RANGE_TYPE_SRVでテクスチャスロット定義
- D3D12_ROOT_PARAMETER_TYPE_DESCRIPTOR_TABLEでディスクリプタテーブル設定
- D3D12_STATIC_SAMPLER_DESCでサンプラー設定

9-2. 描画時の設定
- SetGraphicsRootSignature()でルートシグネチャ設定
- SetPipelineState()でパイプラインステート設定
- srvManager_->SetGraphicsRootDescriptorTable()でSRVを設定
- DrawIndexedInstanced()で描画実行

9-3. シェーダー内での参照
- textureCube関数でキューブマップテクスチャにアクセス
- sample関数で通常のテクスチャにアクセス

========================================
10. 重要なポイント
========================================

10-1. DDSファイル特有の処理
- 圧縮フォーマット（BC1, BC3, BC7等）への対応
- Cubemap（6面テクスチャ）の自動判定
- ミップマップの適切な処理

10-2. パフォーマンス考慮
- 読み込み済みテクスチャの重複チェック
- CommandKickによる適切なGPU同期
- SRVの効率的な管理
